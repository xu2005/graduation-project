# 串口协议 v1

USART1 ↔ PC，115200 baud、8 数据位、无校验、1 停止位（8N1）。每条 ASCII 帧以 `\r\n` 结束；接收端用 LF (`0x0A`) 终止，解析前去掉末尾 CR。数值使用小数点 `.`，不含空格。第一版无 CRC，解析入口保留帧类型判断及校验扩展位置。

| 方向 | 帧 | 行为 |
|---|---|---|
| STM32 → PC | `$SCAN,45.0,123.4,26.0\r\n` | 角度 °、距离 cm、温度 °C |
| STM32 → PC | `$PONG\r\n` | 回应 PING |
| PC → STM32 | `$PING\r\n` | 通信检测 |
| PC → STM32 | `$SET,30,150,2,100\r\n` | 起始角、终止角、步进角、间隔 ms |
| PC → STM32 | `$START\r\n` | 开始扫描 |
| PC → STM32 | `$STOP\r\n` | 停止扫描 |

`SET` 限制：`0 ≤ start < end ≤ 180`、`1 ≤ step ≤ 20`、`20 ≤ interval ≤ 2000`。STM32 收到合法 SET 后从 start 重新扫描；非法 SET 忽略。控制命令不要求 ACK，PING 可用于主动检测。模拟器串口模式启动时停在 STOP，收到 START 才发 SCAN。

接收 SCAN 时必须先核对类型和**恰好四个字段**，再把后三项转换为有限实数（拒绝 NaN/Inf）；角度限 `0..180`，距离限 `(0,400]` cm。空帧、未知帧、字段不足/多余、数字错误和越界都丢弃并标记 Parse Error，不能添加到图或 CSV。PONG 只更新通信状态。下一版可在末尾加校验字段，但需要同步修改 STM32、模拟器与解析 VI。

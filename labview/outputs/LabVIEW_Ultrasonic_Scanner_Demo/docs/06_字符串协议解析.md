# 06 字符串协议解析

选择“先分字段，后逐项转数值”，因为这比一个长 `Scan From String` 模板更容易解释为什么拒绝少字段、多字段和非数字。先 Trim Whitespace/去尾 CRLF，空字符串直接失败；以逗号拆成字符串数组（Spreadsheet String To Array 的字符串类型，分隔符 `,`，或逐次 Match Pattern），要求数组长度恰好 4，首字段恰为 `$SCAN`。然后分别用 `Scan From String` 的 `%f` 格式读取三个数，并检查节点 error out 及是否消耗全部字段，避免 `12abc` 被误认成 12。

验证所有数是有限值：在 LabVIEW 中检查 `Not A Number/Path/Refnum?` 等相应节点及范围比较；角度 `0..180`，距离 `(0, Max Distance]`，温度建议 `-40..80`（DHT11 实际范围应按硬件规格进一步收紧）。失败时输出 valid=false、reason 文本，不把异常点放入 XY Graph 或记录数组。`$PONG` 是另一种帧，在 Main 的类型分支里处理，不调用 SCAN 解析。其他帧显示 Parse Error，但不中止循环。

测试表：`$SCAN,45.0,123.4,26.0` → 有效；空行、`$SCAN,45,123`、`$SCAN,x,123,26`、`$SCAN,45,0,26`、`$SCAN,181,123,26`、`$SCAN,45,401,26`、`$SCAN,45,123,26,9` → 无效。注意有些 LabVIEW 数字转换函数接受数字前缀，因此“消耗全部字符”检查不可省。

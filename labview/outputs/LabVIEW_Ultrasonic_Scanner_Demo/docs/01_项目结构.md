# 01 项目结构

`protocol/` 定义两端共同遵守的 ASCII 帧；`tools/` 是可独立运行的 STM32 Python 模拟器；`labview/` 是各 VI 的逐线搭建说明；`examples/` 提供观察和 CSV 格式样本；`docs/` 按学习顺序讲原理、搭建和排错。

数据流：串口一整行 → 校验 `$SCAN` → 角度/距离/温度 → 极坐标转 XY → 有界点缓存 → XY Graph；同时把有效样本追加到记录数组，Save Data 时统一写 CSV。图缓存清空不删除已记录数据。

控制流：Connect 打开 VISA；START 先发送 SET 后发送 START；STOP 发送 STOP；Disconnect/退出都关闭 VISA。错误帧不停止串口循环；串口硬错误进入 ERROR 并关闭资源。

未包含 `.vi` 和 `.lvproj` 的原因及本机环境见 README。LabVIEW Project 应在 New → Project → Blank Project 建立，命名 `Scanner.lvproj`，把搭好的七个 VI 加入项目；不要给纯文本改 `.vi` 后缀。

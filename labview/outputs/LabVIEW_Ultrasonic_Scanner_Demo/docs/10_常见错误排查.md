# 10 常见错误排查

| 现象 | 检查与处理 |
|---|---|
| 串口打不开/被占用 | 设备管理器确认端口；关掉串口终端；虚拟串口 LabVIEW/Python 分别用配对的不同端。查看 VISA error code。 |
| VISA Read 一直 timeout | LF termination 是否启用、帧是否以 `\r\n` 结束、是否点击 START、baud 是否一致；空闲 timeout 本来正常。 |
| STM32 未响应 | 先 PING/PONG；检查 TX/RX 交叉、GND、3.3 V、电源和 USART1 初始化。 |
| RX Frame 有值但 Parse Error | 检查首字段、逗号数、小数点、CR 清理、数值范围；用示例日志逐行试 Parse VI。 |
| 角度越界/距离非法 | 丢弃帧，查传感器异常值和 STM32 单位换算；不要把 0 或大于 400 cm 的点绘图。 |
| 图不更新或只见线 | X/Y Bundle 型别是否对、点样式是否启用、坐标轴范围是否覆盖测距范围。 |
| 程序停止后 COM 仍占用 | 检查退出共同出口是否经过 VISA Close；错误分支也要 Close。 |
| Python 提示找不到模块 serial | stdout 模式无需包；串口模式执行 `py -m pip install -r tools/requirements.txt`。 |
| 找不到 Python | 安装 Python 3.10+ 或用已有完整解释器路径；`py -0p` 应列出版本。 |
| 图随运行越来越慢 | 确认 X/Y 截到 Max Graph Points；Save Data 记录数组较长时及时保存后可另加“清空记录”操作。 |

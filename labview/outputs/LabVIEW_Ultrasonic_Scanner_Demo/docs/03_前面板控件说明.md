# 03 前面板控件说明

按四个区域从左到右摆放，主窗口 1200×760 左右即可。名称可用“中文（英文）”，英文部分与下表一致。按钮用 Boolean，参数用 Numeric，COM Port 用 VISA Resource Name；数字显示使用 DBL，间隔用 I32/U32。

| 区域 | 控件或显示器 | 默认/限制 | 用途 |
|---|---|---|---|
| 串口 | COM Port | 用户选择 | VISA 资源名 |
| 串口 | Baud Rate | 115200，正整数 | VISA 配置 |
| 串口 | Connect / Disconnect | 按钮 | 打开/关闭 |
| 串口 | Connection Status | Disconnected | 简短文本 |
| 参数 | Start Angle / End Angle | 30 / 150，0–180 | 起止角 |
| 参数 | Step Angle | 2，1–20 | 角度增量 |
| 参数 | Scan Interval | 100，20–2000 ms | 步进间隔 |
| 参数 | VISA Timeout | 200 ms | 整行读取最长等待 |
| 参数 | Max Distance | 400 cm | 超距丢弃阈值 |
| 参数 | Max Graph Points | 500 | 缓存上限 |
| 控制 | START / STOP / Clear Graph / Save Data | 按钮 | 控制与记录 |
| 实时 | Current Angle / Distance cm / Temperature C | DBL | 最近有效帧 |
| 实时 | RX Frame / TX Frame | 字符串 | 最近原始行/发送命令 |
| 显示 | XY Graph | X/Y 单位 cm；X 可设 −400..400，Y 设 0..400 | 二维点云，Plot Style 选点 |
| 显示 | Status | Disconnected | Connected、Scanning、Stopped、Serial Error、Parse Error |

用控件属性 Data Entry 设置数值范围，但 START 事件仍要二次校验 `start < end` 等跨控件条件。COM 默认值依当前机器设置，无法通用；**不固定写死 COM3**。错误提示可加一个 `Last Error` 字符串显示器。Save Data 点击时选择目标 CSV 路径。

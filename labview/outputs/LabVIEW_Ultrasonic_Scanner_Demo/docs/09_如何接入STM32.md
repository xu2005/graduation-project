# 09 如何接入 STM32

STM32F103C8T6 USART1 通常连接 USB 转串口模块的 TX/RX（交叉接）与 GND；核实实际板卡引脚、电源和 **3.3 V 串口电平**，不要把不兼容的 5 V 信号直接接 MCU。Windows 设备管理器找 COM 号；LabVIEW 选对应 VISA 资源。STM32 配 115200 8N1，接收 LF 结束的命令，发送每条 `$SCAN,...\r\n`。

板端建议：主循环或串口命令处理识别 START/STOP/SET/PING；SET 先验证范围再更新扫描参数；扫描定时步进并按当前实际舵机角发帧；HC-SR04 超时/距离无效时不要伪造成合法正数；DHT11 失败可跳过该样本。先用 PC 串口终端验证 `$PING` 得 `$PONG`，再发 SET 和 START 看帧，最后连接 LabVIEW。不要让串口终端与 LabVIEW 同时占用同一个 COM。

若图左右反向，先核对 SG90 的机械 0° 方向。可以在 STM32 发实际角度，或只在 Polar_To_XY 中做 `180-angle` 映射；选择一处修改并在答辩中说明坐标约定。

# 12 测试步骤与验收

## 先测试模拟器（不需要 LabVIEW）

在工程根目录，Python 3.10+ 执行：

```powershell
py -m py_compile tools/stm32_serial_simulator.py tools/test_simulator.py
py -m unittest discover -s tools -p 'test_*.py' -v
py tools/stm32_serial_simulator.py --mode stdout --count 5 --interval 20
```

期望 3 个单元测试通过，stdout 出 5 条 `$SCAN`，每条有角度、距离、温度和 CRLF。2026-09-27 在本机使用 Codex 自带 Python 实际运行了上述静态检查及测试，并额外核对 5 条输出帧与示例 CSV 的 XY 坐标。本机 `py` 启动器未注册 Python，若直接复制上述命令报错，先安装 Python 或把 `py` 换成解释器完整路径。

## 用虚拟 COM 测 LabVIEW（搭好 VI 以后）

1. 配置 COM7↔COM8 虚拟串口；`py -m pip install -r tools/requirements.txt`；运行 `py tools/stm32_serial_simulator.py --mode serial --port COM8`。模拟器显示等待 START。
2. Main 前面板选 COM7、115200、30/150/2/100，Connect → Status 应为 Connected。可加 PING 测 PONG。
3. 点 START → TX Frame 先见 `$SET,30,150,2,100`，后见 `$START`；RX Frame 开始见 `$SCAN,30.0,...`，三个数值与点云更新。
4. 点 STOP → TX Frame 为 `$STOP`，模拟器停止发扫描帧，状态 Stopped。再次 START 可继续。
5. 点 Clear Graph → 点云归零；再次 START 后继续出点。点 Save Data → 选 CSV，检查六列标题、行数及 XY 坐标。
6. 拔掉/关闭模拟器端口观察 Serial Error；输入坏帧应显示 Parse Error 且下一条好帧仍能更新。关闭窗口后重新打开 COM，应不再被上次 VI 占用。

目前没有自动生成的 Main.vi，故上述 LabVIEW 端到端步骤是**搭建后的验收清单**，本次未在真实 VI 上执行。串口模式还需 pyserial 与虚拟串口，当前环境未具备，不能声称已端到端通过。

# 08 参数修改指南

先改 Main 前面板“配置”区域；它是参数唯一入口。下表“常量”指在 VI 内需要同步检查的限制，不要同时散落多个互相矛盾的数字。修改协议字段时三端要同步。

| 想改什么 | 改哪个控件 | 改哪个常量/限制 | 改哪个 VI | STM32 协议是否要改 |
|---|---|---|---|---|
| 波特率 | Baud Rate | 默认 115200 | Main → Serial_Init | 帧格式不变，但 STM32 USART1 波特率必须一致 |
| 默认 COM | COM Port 的默认值 | 无 | Main → Serial_Init | 否 |
| 起始角 | Start Angle | `0..180` 与 `start<end` | Main START 事件 | 否，SET 数值变化；STM32 必须支持该范围 |
| 终止角 | End Angle | 同上 | Main START 事件 | 同上 |
| 步进角 | Step Angle | `1..20` | Main START 事件 | 否，SET 数值变化 |
| 扫描速度 | Scan Interval | `20..2000` ms | Main START 事件 | 否，SET 数值变化；STM32 应按该间隔采样 |
| 串口 Timeout | VISA Timeout | 默认 200 ms | Serial_Init / Serial_Read | 否 |
| 最大测距 | Max Distance | 默认 400 cm、解析范围 | Parse_SCAN_Frame | 帧格式不变；更大量程需确认传感器与 STM32 计算 |
| 图缓存点数 | Max Graph Points | 默认 500，需 >0 | Main 更新图分支 | 否 |
| CSV 保存位置 | Save Data 文件对话框 | 默认目录 `data/` | Main / Save_CSV | 否 |
| 新数据字段 | 新显示器 | 更新字段数、类型、CSV 标题/列 | Parse_SCAN_Frame、Main、Save_CSV | **是**，STM32 和模拟器均要改 |
| 湿度字段 | Humidity C? 应命名 Humidity % | 更新 `$SCAN` 为五字段和 CSV 增列 | 同上 | **是**，DHT11 发送湿度 |
| 扫描状态字段 | Scan State 显示器 | 规定枚举值和在帧中的位置 | 同上 | **是**，或单独定义 `$STATUS` 帧 |

模拟器默认参数另可由 `--start --end --step --interval` 设置；串口模式收到 SET 会动态覆盖。修改 `protocol/protocol.md` 后再改双方代码，避免一方仍按四字段解析。

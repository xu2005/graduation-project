# DHT11 A-01 DWT 轮询驱动

本目录保存 `HC_SR04_ECHO/Drivers/DHT11` 在 A-01 修复后的 `dht11.c` 和 `dht11.h` 原样副本，供后续固件工程复用。不包含 `.ioc`、主程序、CMake 或其他工程硬件配置文件。

- 平台：STM32F1 HAL、Cortex-M3 DWT 计数器；头文件仍包含工程的 `main.h`。
- 当前引脚约定：`DHT11_Init()` 在驱动内部将 DATA 配置到 PB14。移植到其他引脚时，需要单独调整这一约定。
- API：`DHT11_Init()` 与 `DHT11_Read()` 保持原签名；读取成功返回 1，超时或校验失败返回 0。失败不覆盖上次温湿度。
- A-01 修复：读取期间不主动修改 PRIMASK；使用 DWT 计时起始信号和数据脉宽，电平等待有超时，轮询间隔过长时丢弃该帧。
- 调度：应用层按低频周期调用，并避免与需要精确 ECHO 捕获的测距阶段重叠。此目录不包含温度补偿或 HC-SR04 驱动。

该版本在 `HC_SR04_ECHO` 工程中完成 Debug/Release 构建及 DHT11 主机级检查；尚需板上验证实际 DHT11 波形和中断负载下的读数成功率。
